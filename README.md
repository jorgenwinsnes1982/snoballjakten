# Snøballjakten

Snøballjakten er et norsk 3D-akespill for mobil og PC: jag tyvene nedover løypa, kast snøball, hopp, dukk og bytt bane.

Spill: https://jorgenwinsnes1982.github.io/snoballjakten/
